# AGENTS.md

Инструкции для AI-агентов, работающих с этим репозиторием.

## Границы работы

- Вся работа выполняется **только внутри этого репозитория**. Не изменяй файлы вне него (в `$HOME`, `~/.config` и т.п.).
- Конфиги применяет сам пользователь вручную (`make apply <app>` или `apps/<app>/bootstrap.sh apply`). Не запускай команды, которые копируют конфиги в домашнюю директорию или применяют их к системе.
- Для проверки содержимого конфига конкретной программы смотри в `apps/<имя_приложения>/` — там лежат исходные конфиги до применения.

## Структура

- `apps/<name>/` — модуль: `bootstrap.sh` + директория с конфигами (напр. `apps/tmuxinator/config/`).
- `scripts/common.sh` — хелперы, `scripts/apps.sh` — запуск всех модулей.
- Команды: `make install|apply|bootstrap [app]`. Порядок добавления модуля описан в `README.md`.
